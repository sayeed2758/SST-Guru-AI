# SST PERSONAL KNOWLEDGE

The browser library supports TXT/MD/JSON/CSV and attempts PDF extraction.

Ideal structured knowledge item:

{
  "id": "chapter-01-topic-01",
  "subject": "History",
  "title": "Topic name",
  "tags": ["keyword1", "keyword2"],
  "text": "Reliable source passage..."
}

For a large production library, move this to a server/vector database and retain source metadata for citations.
